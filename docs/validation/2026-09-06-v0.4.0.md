The candidate includes Windows-native CLI/TUI support (#16) and shared resource
sorting (#18), merged through PR #25. Cargo.toml and Cargo.lock use 0.4.0.

- Local formatting, 127 tests, Clippy with warnings denied, Windows GNU target
  compilation, and locked release build passed.

- Release-candidate packaging and PR CI results are recorded in the release PR.

## Real-host evidence and limits

- The [Windows-native validation record](2026-09-05-windows-native.md) documents
  earlier packaged Windows/WSL CLI and TUI checks. Those artifacts predate sorting
  and are not the v0.4.0 candidate.
- The user subsequently confirmed Windows Terminal operation. Issue #16 is now
  closed. Additional-distribution lifecycle testing is skipped at the user's
  request because an additional test distribution is unavailable.
- PR #25 verified live WSL JSON ordering and TUI sort switching with a 30-second
  sample interval, plus clean exit and terminal restoration.
- Native Windows interactive sorting has not been manually verified on this
  candidate. Controlled one-core/four-core workloads and deliberate Docker/WSLC
  failure/recovery scenarios have not been repeated for this release preparation.
