# v1.1.1 release preparation — 2026-11-07

## Scope and compatibility

This patch includes the BuildKit attribution and sampling fixes from
[PR #82](https://github.com/adachi6k/wsltop/pull/82), plus the rmcp 3.8 dependency
update already merged since v1.1.0. Embedded BuildKit executor processes appear
under Docker, incomplete Docker observations remain unavailable, and
`--no-docker` preserves WSL CPU/RSS when cgroup metadata changes between samples.
Existing CLI options, JSON fields and units, and the four read-only MCP tools
retain their contracts. WSL kernel CPU remains inclusive while BuildKit overlap
cannot be resolved from common-window cgroup counters.

The candidate starts from main commit
`04759290ba9e8b2c18185d5dd0f50c1a0b0738bf`. Cargo metadata and the changelog select
version `1.1.1`. The changelog date records preparation in Asia/Tokyo; update it
if publication occurs on a later date.

## Real-host coverage

The [BuildKit review validation](2026-11-07-buildkit-review.md) records Windows
GNU execution with Docker Desktop, flat/tree membership without duplicate WSL
rows, and the `--no-docker` fallback. It also records regressions for changing
cgroup metadata and newly discovered distribution baselines. Those checks used
the implementation subsequently merged in PR #82, before this version bump.

The validation host runs Windows 11 Pro build 26200.9711 with 16 logical CPUs,
Ubuntu 24.04.4 LTS in WSL 2, WSL/WSLC 3.0.3.0, kernel 6.18.54.1-1 and Docker
client/server 29.9.2. Ubuntu and docker-desktop are running; the separate
GitHubRunner distribution is stopped.

Candidate archive checks and remaining coverage limits will be recorded here.
