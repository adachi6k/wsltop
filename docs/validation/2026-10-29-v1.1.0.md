# v1.1.0 release preparation — 2026-10-29

## Scope and compatibility

This minor release adds the optional `--hide-windows` display filter and the TUI
`w` visibility toggle from [PR #79](https://github.com/adachi6k/wsltop/pull/79).
The filter preserves Windows collection, summary totals, CPU normalization and
the selected WSL, Docker and WSLC sources. Defaults and the four read-only MCP
tools remain unchanged. It includes the dependency and documentation updates
merged since v1.0.1.

The candidate starts from main commit
`841cb9092320470ebb4a4c85619a7916895237e6`. Cargo metadata and the changelog select
version `1.1.0`. The changelog date records preparation and must match publication.
